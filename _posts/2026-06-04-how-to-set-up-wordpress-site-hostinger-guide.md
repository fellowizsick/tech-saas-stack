## Step 2: Register Your Domain

Once you've selected a plan, Hostinger will prompt you to choose a domain name. Your options:

1. **Register a new domain** — Free with Premium+ plans (e.g., `yourblog.com`)
2. **Transfer an existing domain** — If you already own a domain

Hostinger's domain checker will tell you immediately if your chosen name is available.

## Step 3: Install WordPress Automatically

Here's where Hostinger really shines for beginners. After completing your purchase, log in to **hPanel** (Hostinger's custom dashboard) and look for the **Auto Installer** section:

1. Click **WordPress** in the Auto Installer
2. Select the domain where you want to install WordPress

The entire process takes about **2-3 minutes**. Hostinger handles database creation, file configuration, and SSL certificate provisioning automatically. Once it's done, you'll receive a confirmation with your WordPress admin URL (typically `yourdomain.com/wp-admin`).

### What If Something Goes Wrong?

WordPress installation failures on Hostinger are rare, but if you run into issues, check these common culprits:

- **Domain not propagated:** DNS changes can take up to 48 hours. Use a temporary subdomain to start building immediately.
- **PHP version mismatch:** Hostinger's hPanel lets you change PHP versions easily (Settings → PHP Configuration). WordPress 6+ runs best on PHP 8.1 or higher.
- **Memory limit too low:** Navigate to Hostinger → Settings → PHP Configuration and increase `memory_limit` to at least 256MB.

## Step 6: Create Your First Pages

With your theme and plugins ready, it's time to create content. Every WordPress site needs these essential pages:

1. **Home** — Your landing page. Use Elementor to design a compelling hero section with a clear headline and call-to-action.
2. **About** — Tell visitors who you are and what your site offers.
3. **Contact** — Add a contact form and your email address.
4. **Blog** — If you're publishing articles (and you should be!), this is where they'll appear.

To create a page: go to **Pages → Add New Page**, give it a title, and use Elementor's visual editor to add content. When you're happy, click **Publish**.

### Setting Up a Static Homepage

By default, WordPress shows your latest blog posts on the homepage. To change this:
1. Go to **Settings → Reading**
2. Set "Your homepage displays" to **A static page**
3. Select your Home page and your Blog page
4. Click **Save Changes**

## Step 7: Configure Essential Settings

Before you start publishing content, lock down these WordPress settings:

### Permalinks
Go to **Settings → Permalinks** and select **Post name**. This creates clean, SEO-friendly URLs like `yourdomain.com/post-title` instead of `yourdomain.com/?p=123`.

### Reading Settings
- **Search engine visibility:** Leave this UNCHECKED (unless you're building in staging)
- **Blog pages show at most:** Set to 10 (good for SEO and page load)

### Discussion Settings
- Enable comments if you want reader engagement
- Consider enabling comment moderation to filter spam
- Install **Akismet Anti-Spam** (comes pre-installed) for automated spam filtering

## Step 8: Speed Up Your Site

2. **Optimize images** — Use Smush or ShortPixel to compress images before uploading
3. **Minify CSS and JavaScript** — LiteSpeed Cache can do this automatically
4. **Use a CDN** — Hostinger offers free Cloudflare integration via hPanel

A well-optimized Hostinger WordPress site should load in under 2 seconds, which meets Google's Core Web Vitals requirements and keeps visitors engaged.
