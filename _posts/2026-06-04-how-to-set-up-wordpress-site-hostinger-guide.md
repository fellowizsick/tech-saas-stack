102|### What If Something Goes Wrong?
103|
104|WordPress installation failures on Hostinger are rare, but if you run into issues, check these common culprits:
105|
106|- **Domain not propagated:** DNS changes can take up to 48 hours. Use a temporary subdomain to start building immediately.
107|- **PHP version mismatch:** Hostinger's hPanel lets you change PHP versions easily (Settings → PHP Configuration). WordPress 6+ runs best on PHP 8.1 or higher.
108|- **Memory limit too low:** Navigate to Hostinger → Settings → PHP Configuration and increase `memory_limit` to at least 256MB.

169|## Step 7: Configure Essential Settings
170|
171|Before you start publishing content, lock down these WordPress settings:
172|
173|### Permalinks
174|Go to **Settings → Permalinks** and select **Post name**. This creates clean, SEO-friendly URLs like `yourdomain.com/post-title` instead of `yourdomain.com/?p=123`.
175|
176|### Reading Settings
177|- **Search engine visibility:** Leave this UNCHECKED (unless you're building in staging)
178|- **Blog pages show at most:** Set to 10 (good for SEO and page load)
179|
180|### Discussion Settings
181|- Enable comments if you want reader engagement
182|- Consider enabling comment moderation to filter spam
183|- Install **Akismet Anti-Spam** (comes pre-installed) for automated spam filtering
